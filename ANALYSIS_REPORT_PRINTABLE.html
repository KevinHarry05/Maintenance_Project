Database Query Performance Issues

N+1 Query Problem

Endpoints /complaints/my and /complaints/assigned fetch complaints but don't eagerly load relationships.

Impact: For 100 complaints, executes 100+ queries instead of 2.

Fix: Use SQLAlchemy selectinload(Complaint.user)
